九条路径，从模型能力走向任务执行

Claude：从模型与协议，走向执行生态。
工具使用和 MCP 连接外部世界，Claude Code 将能力落到开发现场；Skills、Cowork 与 Managed Agents 再把任务扩展到知识工作和托管运行。

Codex：从代码专长，走向通用工作空间。
CLI 与云端任务起步，经 IDE、SDK 和桌面应用扩展；模型从编程专用优化，逐步融合电脑操作、研究与端到端任务能力。

千问：开放模型与开发者工具。
Qwen 模型家族持续扩展，Qwen-Agent 与 Qwen Code 把能力带到工具编排与终端编程。

智谱：从基础模型到自主操作。
GLM 发展工程与长任务能力，AutoGLM 探索手机操作，创作 Agent 延伸到办公内容。

Kimi：从研究到并行协作。
Researcher、Agent Swarm、Code 与 Work，逐步连接研究、编程和桌面知识工作。

DeepSeek：以模型与接口连接生态。
推理、工具调用与兼容接口持续演进。这里的 Agent 节点主要是接口能力，不等同于独立 Agent 产品。

MiniMax：从长上下文到任务交付。
M1 与 M2 系列发展推理、编程和工具使用，MiniMax Agent 将多步规划落到实际任务。

DouBao：模型与工作流协同。
Seed 系列发展多模态与复杂任务能力，并通过豆包和 TRAE 承接办公、编程等工作。

Hunyuan：模型能力融入产品生态。
从云端模型服务到开放权重，再到 Hy3，持续加强 Agent 能力与产品集成。
